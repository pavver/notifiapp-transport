# Транспортний рівень NotifiApp Transport

Спільна бібліотека транспортного рівня для сервісів екосистеми NotifiApp.
Вона надає уніфіковані механізми комунікації між клієнтами та серверами.

## Основні можливості

- **WebSocket транспорт**:
  Використовує WebSocket як основний протокол швидкого двостороннього зв'язку.
  Дані серіалізуються за допомогою ефективного бінарного формату `postcard`.
- **Шифрування Noise XX**:
  Забезпечує надійне наскрізне шифрування за допомогою криптографічного протоколу Noise XX.
  Вбудований захист від перехоплення та підміни трафіку.
- **WFQ планувальник (Weighted Fair Queueing)**:
  Дозволяє пріоритезувати критичні повідомлення над фоновим трафіком.
  Забезпечує швидку доставку важливих нотифікацій навіть при завантаженому каналі.
- **Автоматичне перепідключення**:
  Автоматичне відновлення з'єднання у разі обриву з використанням експоненціального бекоффу.
- **Контроль стану з'єднання**:
  Вбудований механізм пінгування (Heartbeat) для виявлення "мертвих" сесій.
- **Резервний HTTP+SSE транспорт**:
  Підтримка класичних HTTP JSON запитів та SSE (Server-Sent Events) підписок для сумісності та спрощеного відлагодження.

## Структура файлів

- [src/lib.rs](src/lib.rs):
  Точка входу, визначення публічного API та реекспорт ключових компонентів.
- [src/auth.rs](src/auth.rs):
  Визначає трейт [AuthHandler](src/auth.rs) для кастомної аутентифікації користувачів.
- [src/crypto.rs](src/crypto.rs):
  Криптографічний шар на базі `snow` для Noise handshakes та шифрування кадрів.
- [src/error.rs](src/error.rs):
  Перерахування помилок [TransportError](src/error.rs) на базі `thiserror`.
- [src/frame.rs](src/frame.rs):
  Рівень фреймінгу, заголовок кадру та підтримувані типу кадрів [FrameKind](src/frame.rs).
- [src/scheduler.rs](src/scheduler.rs):
  Планувальник повідомлень Weighted Fair Queueing з підтримкою пріоритетів [MessagePriority](src/scheduler.rs).
- [src/state.rs](src/state.rs):
  Перерахування станів з'єднання [ConnectionState](src/state.rs).
- [src/ws/](src/ws/):
  Компоненти WebSocket клієнта та сервера.
  - [ws/client/connection_loop.rs](src/ws/client/connection_loop.rs):
    Головний асинхронний цикл обробки клієнтського з'єднання, перепідключення та пінгу.
  - [ws/server/mod.rs](src/ws/server/mod.rs):
    Управління вхідними з'єднаннями та сесіями на стороні сервера.
- [src/http/](src/http/):
  HTTP клієнт та SSE емітер для серверів Axum.
